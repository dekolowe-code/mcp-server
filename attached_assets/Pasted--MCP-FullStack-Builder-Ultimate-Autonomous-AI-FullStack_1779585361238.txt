# MCP FullStack Builder Ultimate

## Autonomous AI FullStack Engineering Platform

> Un serveur MCP ultra-avancé capable d’agir comme un véritable ingénieur logiciel autonome IA.
> Compatible avec Claude Desktop, Cline, Cursor, Windsurf et tout client MCP.

Il peut :

* créer des sites web complets
* créer des applications React / Next.js / Vue / Astro
* créer des applications mobiles React Native / Expo / Flutter
* créer des backends Node.js ou Python
* générer des APIs complètes
* générer bases de données et ORM
* analyser des projets existants
* corriger automatiquement les erreurs
* exécuter commandes terminal
* modifier du code existant
* déployer automatiquement
* fonctionner comme un véritable agent développeur autonome
